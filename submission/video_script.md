# Alternative demo script — target 30 seconds or less

This is a script, not a recorded video. Time a spoken rehearsal before submission. Team/member introduction can be an on-screen caption with actual names supplied by participants.

**0–5 s — coastal map:** “When coastal land sinks, the sea gets closer. This is SinkingCities.”

**5–13 s — city selector and Semarang:** “Our prototype explores real NASA NISAR coverage across five Southeast Asian cities, finding a continuous radar sequence for Semarang.”

**13–22 s — click a catalog footprint, show dates:** “Every observation is traceable. Next, we must correct and validate the radar measurements before claiming a sinking rate.”

**22–30 s — provenance panel:** “Our goal: clear land-motion evidence and honest uncertainty, helping communities understand changing coastal risk.”

Do not show a displacement chart or 2050 result until real measurements exist. Include visible AI-assistance disclosure for generated code in the accompanying project description.
