# Seven-slide demo outline

Status: outline only, not a rendered slide deck. Keep the final deck to seven slides total, including title/intro. Use English. Add actual team/member names before submission.

1. **When the land sinks, the sea gets closer.** SinkingCities; team/member names TODO; challenge: Dancing with the SARs. Identify this as a research prototype.
2. **A local problem with a satellite perspective.** Explain subsidence plus rising water. Use the Jakarta historical literature as context, explicitly dated; do not imply new measurements.
3. **Why NISAR.** Radar through cloud, repeat observations, L-band. Explain what phase can reveal and why coherent observations matter. Cite NASA/ASF.
4. **Start with the evidence.** Show the actual five-city coverage map. Explain scene footprint versus usable-pixel coverage and the full-box screening rule.
5. **A candidate sequence, not a claimed velocity.** Show Semarang's actual acquisition dates and five-pair chain. Describe the next inspection/correction/reference gate. If validated results become available, replace this slide with the real velocity map and point time series.
6. **What a responsible 2050 scenario would require.** Diagram ocean change + continued subsidence, with matched baseline, land-motion accounting and uncertainty. No numerical map until real inputs are loaded.
7. **Trust is part of the interface.** Show the data/limits panel, current blocker, next steps, public link and source citations. Disclose AI-assisted code and distinguish implemented work from planned analysis.
